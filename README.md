# AirBNB SF Listings

A JavaScript/AJAX page that fetches and displays the first 50 Airbnb San Francisco
listings from a local JSON dataset, built as part of a JavaScript and DOM self-assessment.

## Features
- Fetches listing data using `fetch()` and `async/await`
- Displays listing name, description, price, thumbnail, and host's name and photo for each listing
- Displays top 5 amenities per listing
- Handles broken/missing images with a fallback placeholder
- **Creative addition:** sort listings by price (low to high / high to low) via a dropdown

## Tech
- HTML, CSS, vanilla JavaScript
- Bootstrap 5 for layout/styling

## Live Demo
🔗 [View the deployed site](https://thejuu5.github.io/Airbnb_Listings_demo_page/)

## Data Source
Based on Airbnb San Francisco listings data (`airbnb_sf_listings_500.json`), provided for
this class assignment.
